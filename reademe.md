# CSC 235 Bootstrap Components

For this assignment I added a Bootstrap Navbar and a Bootstrap Alert to the CSC 235 sample.

## Navbar

I used the Navbar because it gives the website an easy way to navigate between pages or sections. I added Home, About, and Contact links. The Bootstrap Navbar is also responsive so it can adjust to different screen sizes.

## Alert

I used the Alert component to display a welcome message at the top of the page. Alerts are useful for showing important information or messages to the user.

I chose these two components because they are common parts of websites and Bootstrap makes them easy to add and responsive.
